# Docs Team - Published Documents

Final, formatted documents published by the docs team. The unformatted originals live in the raw documents repository.

## Tracks
| Folder | Track |
|---|---|
| `system-design/` | System Design |
| `machine-learning/` | Machine Learning |
| `dsa/` | DSA |
| `devops/` | DevOps |
| `web-dev/` | Web Dev |
| `java/` | Java |

Logos and other formatting resources are in `assets/`.

## Naming
Use the same base name as the raw document with the final format, for example raw `week-02-file-handling.md` becomes `week-02-file-handling.pdf`.

## How to publish
1. Format the raw document.
2. Upload the final file to the matching track folder (Add file > Upload files).
3. Close the "Format: ..." issue in the raw repo with a link to the published file.
